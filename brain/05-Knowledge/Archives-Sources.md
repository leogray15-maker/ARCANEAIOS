# What HERALD may cut from

The Archives mix Leo's own courses with material saved from elsewhere.
HERALD only makes public content from the first kind. This list is the
gate: a subject (course hub) must appear under **Allowed** for HERALD to
pick from it on its own. Edit it in Obsidian; HERALD reads it on every
run. Match is by substring, case-insensitive. A subject under **Never**
is refused even when named.

`npm run herald:pick -- --any-subject` bypasses the allow list for a
one-off, but the Never list still holds.
